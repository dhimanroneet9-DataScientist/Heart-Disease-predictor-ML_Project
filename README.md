# Heart Disease Risk Predictor
Logistic Regression model deployed with Streamlit.

Run locally:
    pip install -r requirements.txt
    streamlit run app.py

Deploy free: push this folder to GitHub, then share.streamlit.io -> New app -> pick the repo and app.py.

Files: app.py (UI), preprocess.py + preprocess.json (exact notebook preprocessing), model.pkl (trained model), columns.pkl (feature order).
